# Choix de la pile technique

## AWS VPC

AWS VPC sera utilisé pour créer le réseau isolé du projet.

## Subnet public

Le subnet public hébergera le Bastion Host.

## Subnet privé

Le subnet privé hébergera le serveur qui doit être protégé.

## Security Groups

Les Security Groups permettront de contrôler les flux réseau.

## Ubuntu Server

Ubuntu Server sera utilisé pour le Bastion et le serveur privé.

## SSH

SSH sera utilisé pour l'administration distante.

## Kali Linux

Kali Linux sera utilisé pour réaliser les tests de sécurité.

## Wireshark

Wireshark sera utilisé pour analyser le trafic réseau.

## GitHub

GitHub sera utilisé pour versionner la documentation, les configurations et les scripts du projet.
